================================================
STEP 1 — CREATE THE NEW GITHUB REPOSITORY
================================================

1. Sign in to GitHub.

2. Click your profile picture in the upper-right.

3. Click "Your repositories".

4. Click the green "New" button.

5. OWNER:
   natalia-borrego

6. REPOSITORY NAME:
   comparative-lion-research

7. Description is optional. Suggested:
   Collaborative comparative African lion behaviour research programme.

8. Set visibility to:
   Public

9. Do NOT add a README.
10. Do NOT add .gitignore.
11. Do NOT add a license yet.

12. Click:
    Create repository


================================================
STEP 2 — UNZIP THIS PACKAGE ON YOUR MAC
================================================

Double-click the downloaded ZIP.

Inside the folder you should see:

index.html
assets
README_SETUP.txt

You will upload index.html and assets.

README_SETUP.txt is only for your own reference.


================================================
STEP 3 — UPLOAD THE WEBSITE
================================================

On the empty GitHub repository page:

1. Click:
   uploading an existing file
   OR
   Add file -> Upload files

2. Drag in:
   index.html
   assets

3. IMPORTANT:
   Upload the CONTENTS so index.html is at the repository root.

Correct:

comparative-lion-research/
  index.html
  assets/

Wrong:

comparative-lion-research/
  comparative-lion-research/
    index.html

4. Scroll down.

5. Commit message:
   Initial programme website

6. Click:
   Commit changes


================================================
STEP 4 — TURN ON GITHUB PAGES
================================================

1. At the top of the repository click:
   Settings

2. In the left sidebar click:
   Pages

3. Under "Build and deployment":

   Source:
   Deploy from a branch

   Branch:
   main

   Folder:
   / (root)

4. Click:
   Save

5. Wait a few minutes.

6. Open:

https://natalia-borrego.github.io/comparative-lion-research/

If you see an old/blank page:
Command + Shift + R


================================================
STEP 5 — REPLACE PLACEHOLDER PHOTOS
================================================

The easiest system is ALWAYS to keep the filename the same.

Example:

assets/images/namibia.jpg

To replace it:

1. Export your real image as a TRUE JPEG.
2. Name it exactly:
   namibia.jpg
3. In GitHub open:
   assets -> images
4. Delete the placeholder namibia.jpg.
5. Commit.
6. Upload your real namibia.jpg.
7. Commit.

No HTML change is needed.

IMAGE FILES:
hero.jpg
namibia.jpg
botswana.jpg
zimbabwe.jpg
methods.jpg
partners.jpg
